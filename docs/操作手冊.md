# 📘 股票紀錄系統 操作手冊

> 這份手冊說明這套系統是什麼、每一頁怎麼用，以及它幫大家省下了哪些時間與麻煩。
> 有看不懂或想新增的內容，直接在群組跟 Jonathan 說。

---

## 一、這是什麼？

這是一套**台股交易記帳系統**，用來取代原本的 Excel 記帳。

**目的**
- **輸入一次，報表全部自動算好**：買進、賣出 key 一次，均價、損益、交割金額、手續費、證交稅都會自動算出來。
- **數字一致、不會打架**：每一頁都用同一套計算方式，不會發生 A 表和 B 表對不起來的情況。
- **隨時隨地都能看**：電腦、iPad、手機開瀏覽器就能用，不用傳檔案。
- **資料安全**：資料存在雲端資料庫，每天自動備份，大量刪除前也會先備份。

**誰在用**：Peggy姐、雅雲姐、王小姐等買賣人的交易，都記在同一套系統裡，各自分開計算。

## 二、第一次使用

### 1. 打開系統
用瀏覽器（Chrome 或 Safari）打開系統網址，輸入**帳號**和**密碼**，按「登入」。

- 「記住我（90 天內免登入）」預設是勾選的，勾著的話 90 天內不用重新登入。

### 2. 加入書籤（很重要）
登入後網址列會變得很長，後面多了一串 `?rt=…`，這是「記住我」用的。
請把**系統首頁**加入書籤，不要在其他頁面加書籤，不然每次打開都會跑到那一頁，而不是「股票輸入（仿Yahoo）」。

### 3. 怎麼修改密碼（一步一步來）
> ⚠️ **改之前先看**：目前大家共用同一個「admin」帳號。密碼改了以後，
> **所有用這個帳號的人（含 iPad、手機）都會被登出，要用新密碼重新登入**。
> 請先決定好新密碼、寫在紙上，改完再告訴需要的人。

1. 登入系統。
2. 看畫面**左邊的選單**，往下找到「**帳號與權限**」，點它。
   （如果看不到，先點選單最下面的「**View more**」把選單展開。）
3. 畫面中間會看到「帳號清單與權限」，找到寫著 **admin（管理者）** 的那一個框。
4. 在框裡找到「**重設密碼（留白不變）**」的格子，點一下，輸入你的**新密碼**。
   - 這個格子只會顯示圓點 ●●●，**打字要慢一點、確定沒打錯**（只輸入一次，沒有第二次確認）。
   - 「帳號」那一格**不要動**。
5. 按右邊紅色的「**儲存帳號設定**」。
6. 出現綠色的「**已更新 admin**」就完成了。
7. 測試：點左下角「**登出**」，再用**新密碼**登入一次，能進去就沒問題。

**萬一新密碼忘了或打錯、登不進去**：直接找 Jonathan 幫忙重設，資料不會因此不見。

## 三、每天怎麼用

### 記一筆「買進」
1. 打開「**股票輸入（仿Yahoo）**」。
2. 上面一排是分頁（例如「Peggy姐」），**在哪個人的分頁輸入，交易就記在那個人名下**。
3. 找到那檔股票（可以用「🔍 股名／股號」搜尋），點左邊的 **▸** 展開。
   - 還沒有這檔股票：按「**新增股票**」先加進來。
4. 在「新增交易」那一列輸入：日期、選「**買入**」、**股數**、**股價**。手續費會自動算好顯示在右邊。
   - 同一檔一次要記好幾筆買進：按「**＋ 再加一筆買入**」。
5. 確認無誤後按紅色的「**✅ 確認新增：買入 ○○ 股 @ ○○**」。

### 記一筆「賣出」
1. 同上，展開那檔股票，選「**賣出**」，輸入股數、股價。
2. 如果是**當沖**，記得勾「**當沖**」（證交稅會減半）。
3. 下面會出現「**沖銷配對**」：這筆賣出要對掉哪幾筆買進。
   - 預設是「接近均價」，也可以改成先進先出、賺多、賺少、賠多、賠少。
   - 可以逐筆改「本次沖銷」的股數，合計要等於賣出股數才能送出。
4. 按「**✅ 確認新增：賣出…**」。

### 改錯或刪除
- 展開股票後，下面「交易明細」每一筆右邊有：
  - **✏️**：修改日期、股數、股價（手續費和稅會自動重算）。
  - **🗑**：刪除（會再問一次確認，相關的沖銷配對也會一起刪掉）。
- 要改「買／賣」方向：請刪掉重新 key。

### 輸入小提醒
- **股價打完、游標還在股價格子時，不要按鍵盤的 ↑ ↓**：每按一下股價會加減 0.05 元。
- 打完數字按 **Enter** 或點旁邊空白處，數字才會算進去。
- 跟券商對帳時發現差幾十元，多半是**某一筆股價差了 0.05**，先逐筆對照成交價。

## 四、每一頁在做什麼

| 頁面 | 用途 | 什麼時候看 |
|---|---|---|
| **股票輸入（仿Yahoo）** | 主要的輸入頁。像 Yahoo 股市的持股明細：市值、已實現、未實現、底價，展開即可買賣 | 每天下單後 |
| **當日交易明細** | 當天（或一段期間）的每一筆買賣、交割應收應付、每股損益簡表；第三個分頁是「期間獲利表」 | 每天收盤後對帳、看交割 |
| **投資績效** | 一段期間的整體表現：未實現、已實現、最佳／最差個股、勝率、獲利與虧損前五名、產業分布 | 想看整體成績時 |
| **已實現損益** | 已經賣掉的部分賺賠多少：依產業、個股排名與佔比、每月趨勢、每一筆「買→賣」明細，可匯出 | 月底、年底結算 |
| **庫存損益** | 目前手上的股票：持倉市值、未實現損益、底價 | 想看還沒賣的部分 |
| **個股明細** | 單一檔股票的庫存明細和已出售明細，含小計 | 想深入看某一檔 |
| **操作手冊** | 就是這一頁 | 忘記怎麼用時 |
| **交易輸入** | 舊版的輸入頁，功能跟仿Yahoo 類似，可以直接在表格裡改手續費 | 需要手動改手續費時 |
| **交易匯入** | 把券商匯出的 CSV／Excel 交易紀錄一次匯進來 | 大量補資料時 |
| **自定沖銷設定** | 指定某筆賣出要對掉哪筆買進，或查看、刪除已配對的紀錄 | 沖銷要調整時 |
| **主檔設定** | 每個人的**手續費折數**（例：Peggy姐 2.5 折、一般 2.8 折）、證交稅率、手續費／當沖稅重算工具（僅管理者） | 折數有變時 |
| **帳號與權限** | 新增帳號、改密碼、設定一般帳號能看哪些買賣人（僅管理者） | 改密碼、加同事時 |
| **AI 問答助理** | 用打字問問題，例如持股狀況、某檔股票的即時報價或財報 | 想快速查資料時 |
| **v2 分析報告對話** | Jonathan 維護的台股分析報告，可以針對報告提問 | 參考用 |

**各報表頁共同的用法**
- 最上面是「**篩選條件**」：快速按鈕（當日／近3天／當週／當月／當年／近1年／全部）、開始／結束日期，**買賣人在最右邊**。
- 最重要的數字放在第一排、大字顯示。
- 計算方式的說明都收在頁面最下面的「📖 說明」，點開就能看。

## 五、名詞小辭典

| 名詞 | 意思 |
|---|---|
| **均價（持股成本均價）** | 手上這檔股票平均每股的成本，含買進手續費 |
| **底價（藍字）** | 全部賣在這個價格，扣掉賣出手續費和證交稅後**剛好不虧**的最低價。會比均價高一點，因為要扣費用；點「🧮 底價怎麼算？」可以看每一步怎麼算 |
| **沖銷** | 把一筆賣出和之前的買進對起來，才算得出這筆賺多少 |
| **已實現損益** | 已經賣掉的部分，實際賺或賠的錢（扣掉手續費、證交稅） |
| **未實現損益** | 還沒賣的股票，用現在股價算的賺賠 |
| **交割應收／應付** | 賣出可以拿回的錢／買進要付出的錢（已含手續費、稅），兩天後交割 |
| **當沖** | 同一天買進又賣出，證交稅只收一半（0.15%） |
| **手續費** | 成交金額 × 0.1425% × 折數，小數無條件捨去，最低 1 元 |
| **證交稅** | 賣出才收，一般 0.3%、當沖 0.15%、ETF 0.1%，小數無條件捨去 |
| **紅色／綠色** | 照台股習慣：**紅色＝賺、綠色＝賠** |

## 六、為什麼要做這套系統？優化帶來哪些效益

### 從 Excel 到系統
| 以前（Excel） | 現在（系統） |
|---|---|
| 每筆交易要手動算手續費、稅、均價 | 輸入股數和股價，**全部自動算** |
| 不同表格各自計算，常常對不起來 | 所有頁面**同一套計算**，數字一致 |
| 檔案要傳來傳去、怕改到別人的版本 | 大家用**同一個網址**，看到的永遠是最新的 |
| 要自己判斷「賣多少才不虧」 | 每檔直接顯示**底價**，還能看計算過程 |
| 打錯數字很難發現 | **防呆**：價格超出漲跌停會擋下（多半是打錯小數點）、賣超過持股會擋下、2 秒內重複送出會擋下 |

### 這幾週依大家回饋做的優化
- **存檔變快**：資料從 Google 試算表搬到雲端資料庫，每次存檔從約 **4.9 秒變成 0.12 秒**。
- **輸入不卡頓**：輸入區改成只更新那一小塊，離開一個格子到畫面更新，從約 **2 秒變成 0.35 秒**，打字不會再被洗掉。
- **股價自動更新**：盤中每 30 秒自動更新股價（正在輸入時會暫停，不會打斷你）。
- **資料更安全**：每天晚上 10 點自動備份一份到 Google 試算表；大量刪除前一定先備份；清空全部資料要手打確認字樣。
- **報表更好讀**：每頁重點數字放最上面、說明放最下面，篩選條件統一位置。
- **更貼近實際**：當沖證交稅減半、每個人可以設不同的手續費折數、新增期間獲利表、每股當日損益簡表。

## 七、常見問題

**Q：畫面出現紅色錯誤訊息怎麼辦？**
先按瀏覽器的「重新整理」。如果還是一樣，截圖傳給 Jonathan。通常是系統剛更新，重新啟動後就會好。

**Q：系統算的金額跟券商差一點點？**
1. 先逐筆對照**成交價**（最常見：某一筆差 0.05 元）。
2. 再對照**手續費**：每個人的折數不同，可以到「主檔設定」看折數設定對不對。
3. 都對還是不一樣，截圖兩邊給 Jonathan。

**Q：股價怎麼沒更新？**
收盤後股價不會變。盤中每 30 秒自動更新，展開股票輸入時會暫停；也可以按「🔄 更新股價」立刻更新。

**Q：打開系統不是在「股票輸入（仿Yahoo）」？**
書籤存到別的頁面了。請打開系統首頁，再重新加入書籤。

**Q：刪掉的交易可以救回來嗎？**
可以找 Jonathan。系統每天晚上 10 點都有備份（大量刪除前也會先備份），可以從備份找回來。
