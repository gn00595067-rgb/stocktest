# 資料庫額度監控（Neon 免費版運算時數）

## 需求（Jonathan 2026-10-16）
- Neon 免費版每月 100 CU 小時，用完資料庫會暫停到下個計費週期；10/2～10/16 已用 71.52（上限設 2 CU 造成）。
- 超額時系統只會出現看不懂的紅框 → 要講清楚原因與處理方式。
- 用完之前要先提醒，讓管理員有時間調整或升級。

## 設計
1. **超額時講清楚**（`services/auth_service.ensure_bootstrap_admin`：每頁第一個碰資料庫的地方）
   - 連不上資料庫時攔下來，不再丟紅框錯誤。
   - 錯誤訊息含 Neon 的額度字樣（quota／exceeded）→ 顯示「資料庫本月免費額度已用完，資料都在；請系統管理員到 Neon 後台升級方案或等下個計費週期」。
   - 其他連線錯誤 → 「資料庫暫時連不上，請稍後重新整理」。
2. **事前預警**（`services/neon_usage.py`，讀 Neon API `GET /projects/{id}` 的 `compute_time_seconds`＝CU 秒、`consumption_period_start/end`）
   - 管理者側欄：「資料庫本月用量 X / 100 CU 小時（重置日 M/D）」，≥70 黃字提醒、≥90 紅字；1 小時快取。
   - GitHub Actions 每天台灣 09:00 檢查（`scripts/check_neon_usage.py`），≥80 讓 workflow 失敗 → GitHub 寄信。
   - 需要 `NEON_API_KEY`（Neon 後台建立）：Streamlit Secrets（側欄用）＋ GitHub repo secret（每日檢查用）；沒設就不顯示、不檢查。
   - `NEON_PROJECT_ID` 選填；沒填時取帳號下唯一的專案（或名稱 stocktest）。

## 不做（先不做）
- 不自動升級方案、不自動調運算上限（都在 Neon 後台手動）。
