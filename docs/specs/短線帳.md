# 短線帳（2026-11-10）

## 需求
老闆撥約 2 千萬資金專做短線（短進短出），要能單獨統計短線的損益與績效。
短線與長線在**同一個證券帳戶**，但對帳單匯入時通常一段日期區間內全部是短線或全部是長線。

## 做法：開一個「短線」買賣人（不改程式）
- 新增買賣人，例：`老闆-短線`。短線的交易全部記在這個買賣人下面。
- 為什麼不用「交易標籤」：沖銷是以「買賣人＋股票」配對。同一檔股票長短線都有買時，
  只加標籤的話，賣短線那張可能被 FIFO 配到長線的舊買進，短線損益就錯了。
  用買賣人分開，配對、庫存、已實現、績效全部天然分開。詳見 DECISIONS.md 2026-11-10。

## 設定步驟（一次性）
1. 「交易輸入」頁新增買賣人 `老闆-短線`。
2. 「主檔設定」→ 買賣人手續費折數：設成和老闆相同的折數（同一個券商帳戶）。
3. 「帳號與權限」：要看短線帳的登入帳號（非管理者）綁定 `老闆-短線`。

## 日常操作
- **對帳單匯入（〇）**：短線區間的對帳單，「匯入到哪個買賣人」選 `老闆-短線`。
  少數混到長線的幾筆，勾「有幾筆要算在別人帳上」逐筆改回老闆。
- **手動輸入**：買賣人選 `老闆-短線`。
- **已經記在老闆名下的短線交易**：到股票輸入（仿Yahoo）明細表把「買賣人」改成 `老闆-短線`
  （買進和對應的賣出都要改，改完系統會重新配對）。

## 看績效
- 投資績效／已實現損益／庫存損益頁：買賣人篩 `老闆-短線` ＝ 短線績效。
- 投資績效頁「依買賣人加總」可並排比較長線 vs 短線。
- 仿Yahoo 可開一個短線分頁；要看老闆長＋短合計，分頁勾選多人即可。

## 限制
- 同一檔股票長短線各自配對：長線的庫存不能拿來沖短線的賣出（這是刻意的）。
- 若之後要「報酬率＝短線損益 / 2 千萬」這類指標，再另外做（目前未做）。
