# 庫存模擬（代操扣除）— 規格

> 狀態：MVP（2026-10-22）
> 需求來源：Peggy（Excel 計算面板截圖）＋ Jonathan

## 1. 要解決什麼
Peggy 會幫系統外的人（例：王小姐）用自訂的價格／張數代操。想先算算看：如果把其中幾張以某個價格「劃給」王小姐，
系統裡剩下的連動庫存還有幾張、均價變多少。原本用 Excel 手抄系統庫存再算，數字要自己對。

## 2. 範圍
- 新增一頁「庫存模擬」。**純模擬，不寫回任何資料**（不新增交易、不改沖銷）。
- 連動的人：多選（預設＝所有目前有庫存的買賣人）；只列這些人合計有庫存的股票。
- 模擬對象名稱可改（預設「王小姐」），只是畫面標籤。
- 每檔可填：模擬對象張數、價格（不含手續費）。沒填＝不扣。
- 手續費折數畫面上可調（預設系統折數 2.8 折）：模擬對象均價（含手續費）＝價格 ×（1＋0.1425%×折數）。不計最低 1 元。
- 扣除口徑可切換（Jonathan 2026-10-22：兩種都要能選）：
  - 不含手續費（同 Excel）：扣除後總成本＝連動總成本 − 張數×價格
  - 含手續費：扣除後總成本＝連動總成本 − 張數×價格×（1＋費率）
- 不做：多個模擬對象、賣出端的模擬。（存檔見 §6，2026-10-27 起要存）

## 3. 計算
- 每人每檔的持股與成本：`compute_position_and_cost_by_stock`（自定沖銷＋其餘先進先出，含買進手續費），與仿Yahoo、庫存損益頁同口徑。
- 連動合計張數＝各人股數加總÷1000；連動均價＝各人剩餘成本加總÷股數加總。
- 扣除後張數＝合計 − 模擬張數；扣除後均價＝扣除後總成本÷扣除後股數。
- 模擬張數超過連動庫存：該列標「超過庫存」，不算扣除後均價。

## 4. 畫面
1. 上方設定：連動的人（多選）、模擬對象名稱、手續費折數、扣除口徑。
2. **單一表格，一邊填一邊算**（Peggy 2026-10-22：輸入表、結果表合成一張）：股名｜連動張數｜連動均價｜各人張數…｜✏️模擬張數｜✏️模擬價格（不含手續費）｜扣除後張數｜扣除後均價（黃底）｜模擬均價（含手續費）。填完按 Enter／點別格就重算。
3. 沒填＝0＝不扣（表格元件空值會顯示 None，所以補 0）。
4. 換人、換口徑時已填的模擬張數／價格保留；離開再進來也保留（§6）。

## 5. 驗收
- 台積電：三人 18 張、均價 2415，模擬 10 張 @2420、不含手續費 → 扣除後 8 張、均價 2408.75（同 Excel 2408.8）。
- 聯電：64 張 @130，模擬 30 張 @132 → 34 張、128.24（同 Excel 128.2）。

## 6. 最後狀態存檔（Peggy 2026-10-27）
- 需求：王小姐的張數／價格手 key 後要存著，「除非再手動改過」；連動的人每次進來都回到全部四人，數據就不對（她要 P＋豪＋雲）。
- 存：連動的人、模擬對象名稱、折數、扣除口徑、每檔填的張數與價格。**每個登入帳號一份**（老闆／開發者互不影響）。
- 每次改值後自動存（跟上次存的一樣就不寫）；進頁面時讀回。沒存過＝預設（連動＝目前有庫存的所有人）。
- 存在資料庫新表 `sim_states`（owner, data JSON, updated_at），`services/sim_state.py` 第一次用到才建表（免 Reboot）；
  用 engine 直接寫、不經 ORM Session，不會讓交易快取失效。試算表備份不含此表。
- 仍然**不動交易、沖銷**；這只是頁面的填寫內容。
- 不要的值：填 0。
