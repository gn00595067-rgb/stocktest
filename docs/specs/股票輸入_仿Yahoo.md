# 股票輸入（仿 Yahoo 奇摩）— 規格

> 狀態：MVP 開發中（2026-10-05）
> 需求來源：Elsa（同事回饋）＋ Jonathan

## 1. 要解決什麼
同事回饋（原文重點）：
- 介面要像 Yahoo 奇摩股市「持股明細」一樣乾淨直覺；不是每天盤中當下要看的東西請收起來。
- 重點在**正確輸入、防呆**，盤中**快速更新**畫面，**即時呈現最新庫存均價**。
- 可以像 Yahoo 一樣**自由新增分頁**，每個分頁決定要看哪些資料（任意股票、日期，可重複）。

## 2. 範圍決策
- **新增一頁**「股票輸入（仿Yahoo）」，舊的「交易輸入」頁保留不動；新頁穩定後再決定是否取代。
- **分頁＝存起來的篩選條件**（Jonathan 2026-10-05 選定）：交易仍只有一本總帳；分頁只是「哪些股票、哪段日期」的條件。同一筆交易可同時出現在多個分頁；新增交易會出現在所有符合條件的分頁。
- **每個買賣人各自一組分頁**（Jonathan 2026-10-05 選定）。
- 不做（之後再說）：摘要資料頁籤、自訂欄位、自選股行事曆、投資健檢、拖拉排序。
- **賣出要有沖銷配對**（2026-10-05 Jonathan 追加）：口徑同舊頁——預設接近均價，可換先進先出／賺多／賺少／賠多／賠少、全部／近3天／近5天，可逐批改「本次沖銷」，合計須等於賣出股數才能送出；送出時交易與沖銷規則同一筆存檔。沖銷的買進批次以該買賣人全部交易為準（不限分頁）。

## 3. 資料
新表 `portfolio_groups`（只存條件，不存交易）：

| 欄位 | 說明 |
|---|---|
| id | 自動編號 |
| trader | 屬於哪位買賣人 |
| name | 分頁名稱（例：1001起、10月短線） |
| start_date / end_date | 交易日期範圍，可留空＝不限 |
| stock_ids | 逗號分隔的股票代號；也是「新增股票」的清單（0 股也會顯示一列，方便輸入第一筆） |
| only_listed | 勾選＝只看清單內股票；不勾＝該買賣人全部股票 |
| sort_order | 分頁排序 |

- 每位買賣人永遠有一個內建「全部」分頁（不存表、不能刪）。
- 刪除分頁**只刪條件，絕不刪交易**。
- 資料庫模式才會長期保存（正式站已是）；試算表模式重啟後分頁會消失（分頁不寫入試算表）。

## 4. 計算（與其他頁同一套引擎）
- 分頁內的持股、均價、已實現、未實現：只用「符合分頁條件的交易」計算，引擎同 `compute_position_and_cost_by_stock` / `compute_matches`（自定沖銷＋其餘先進先出）。
- 已實現％＝已實現淨損益 ÷ 被沖銷買進的成本（含買進手續費）。
- 未實現％＝未實現 ÷ 持股成本（含買進手續費）。
- ⚠️ 有起始日的分頁：若分頁內的賣出找不到分頁內的買進（買在起始日之前），畫面明確提示「N 筆賣出在此分頁找不到對應買進」，這些股數不計入分頁的已實現。

## 5. 畫面（對照 Yahoo）
1. **分頁列**：全部｜1001起｜10月短線…；右側「新增分頁」。目前分頁下方：新增股票｜編輯此分頁｜刪除此分頁｜← →（排序）。
2. **總覽卡**：持有股票市值（大字）、已實現損益（金額＋％）、未實現損益（金額＋％）、報價時間。紅▲賺、綠▼賠（台股慣例，同 Yahoo）。
3. **持股表**：股名/股號｜股價/漲跌(%)｜持有股數｜持股成本均價｜市值｜已實現損益｜未實現損益｜交易筆數｜展開鈕。依市值由大到小。
4. **展開某檔**：列出該檔在此分頁的每筆交易（交易日期、買入/賣出、交易股數、交易股價、市值），每筆右邊 🗑（需確認）；最下面一列「新增交易」：日期、買/賣、股數、股價、送出。
5. 展開區用 fragment：輸入時不整頁重畫；送出／刪除成功才整頁更新。

## 6. 防呆
- 股數、股價必須 > 0；股數不是 1000 的倍數時提示「零股？」但可送出。
- 股價超出昨收 ±10%（漲跌停外）：擋下並提示（多半是打錯小數點）。
- 賣出股數 > 該買賣人目前總持股：擋下。
- 交易日期在分頁日期範圍外、或股票不在「只看清單」內：提示「送出後不會出現在此分頁」，需勾選確認才送出。
- 送出前顯示一行確認摘要（買/賣、股數、價格、手續費、證交稅），按「確認送出」才寫入；2 秒內重複送出相同內容會被擋。
- 刪除交易需確認；刪除會連帶刪除相關沖銷配對。
- **交易明細可修改**（2026-10-07 Jonathan 追加）：每筆有「✏️」可改日期／股數／股價（買賣方向不給改，要改請刪掉重 key）。股數或股價有改 → 手續費／稅依費率重算；股數有改 → 這筆的自定沖銷配對清掉，改回預設沖銷（同舊頁口徑，會先提醒）。防呆同新增，另擋「買入改少後持股變負」。
- **沖銷配對表全部展開不留捲軸**（2026-10-07）：一頁看完所有可沖銷的買進批次。

## 7. 驗收
- 新增／編輯／刪除／排序分頁；刪分頁後交易筆數不變。
- 分頁條件正確篩選；同一筆交易可出現在兩個分頁。
- 「全部」分頁的持股股數、均價與舊「交易輸入」頁一致。
- 防呆各情境都會擋下或提示。

## 2026-10-07 Peggy 第二輪回饋

- **分頁口徑改成「以買進歸屬」**：沖銷用該買賣人全部交易照全站引擎配對，分頁只算「買進日期／股票符合條件」的批次。
  - 持股、均價＝這些批次剩下的股數與成本；已實現＝賣出沖到這些批次的部分（賣出日期不限，晚於分頁結束日也算）。
  - 賣出沖到分頁外舊批次的，不算進此分頁（不再顯示「找不到對應買進」的提示）。
  - 「全部」分頁數字與庫存損益頁一致。交易明細仍列出分頁日期內的所有買賣。
- **持股表加「賣出平本底價」**（持股成本均價與市值之間）：全部股數以此價賣出，扣賣出手續費與證交稅後剛好不賠（`breakeven_sell_price`）。
- **新增交易：買入可多列一次送出**（「＋ 再加一筆買入」、每列可 ✕ 移除、空白列略過）；同一次存檔，全成功或全不存。賣出維持一次一筆（要配沖銷）。
- **賣出可勾「當沖」**：證交稅減半，交易標記 is_daytrade，明細顯示「賣出（當沖）」。
- **交易明細欄位**：日期｜買賣｜股數｜股價｜手續費｜稅（小字）｜市值｜✏️｜🗑，新增列與明細欄寬對齊。

## 2026-10-07 Peggy 第三輪：人＝分頁（像奇摩投資組合）、每個分頁可改名

- **拿掉右上角「買賣人」下拉**。分頁列就是投資組合清單，每個分頁記著「哪個人（買賣人）」。
- 分頁兩種（同一張表，看有沒有條件）：
  - **人的全部帳**：沒設日期、沒限定股票＝那個人的全部交易（原本的「全部」）。例：Peggy姐、小孩、王小姐。
  - **篩選分頁**：某個人＋日期範圍／股票清單（例：1001起）。口徑仍是「以買進歸屬」。
- 在哪個分頁輸入交易，就記在那個分頁的人名下。
- **每個分頁都能改名、排序、刪除**（含原本的「全部」）；刪分頁絕不刪交易。全部刪光時自動補回一個預設的人的分頁。
- **分頁屬於登入帳號**（`portfolio_groups.owner`＝登入帳號）：每個帳號只看到自己加過的分頁；admin 不會被所有買賣人的分頁塞滿。分頁的人必須是該帳號有權限的買賣人，失去權限的分頁自動隱藏。
- 新增分頁對話框：名稱、哪個人（admin 可直接「＋ 新增人」，會同時加入買賣人名單）、類型（全部帳／只看某段日期或某些股票）。
- 舊資料遷移：帳號第一次進來時，自動建一個「預設買賣人」的全部帳分頁（名稱＝買賣人名），並把還沒有擁有者、且有權限的舊分頁（例：1001短線）歸到這個帳號。
- 「新增股票」在任何分頁都存進該分頁的股票清單（之前「全部」只存在瀏覽器暫存，重整就不見）。
