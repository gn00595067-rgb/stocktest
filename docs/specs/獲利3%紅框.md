# 獲利 3% 紅框提醒（股票輸入（仿Yahoo）持股表）— 新舊版一起做

## 需求（2026-11-19 Peggy）
> 你都已經給我報價可以銷售，也就是有獲利提醒我可以銷售，那麼你要不要再幫我在股票上面只要有三%獲利就直接幫我標注出來，
> 尤其是這兩天我都在短線進出，早上買當我 key in 進去只要有三%你就提醒我用紅框標示出來趕快銷售。

## 規則
- 「獲利 %」沿用「💰 已過底價 +x.x%」那個數字：(現價 − 底價) ÷ 底價。底價已扣賣出手續費＋證交稅，
  所以 +3% ≈ 今天全部賣掉、扣完費稅後淨賺約持股成本的 3%。畫面上看到的 % 跟紅框門檻是同一個數，不會對不起來。
- **≥ 3%**：整列加紅框（表格列、窄畫面卡片都要），股名下標「🔴 獲利 +x.x% 可賣」。
- 不受「💰 可賣的排上面」開關影響：開關關著也照樣框（Peggy 收盤後也可能看）。
- 每個分頁都適用（含短線分頁）；報價每 20 秒更新，紅框跟著出現／消失。
- 門檻先寫死 3%（`SELL_ALERT_PCT`）；有人要不同門檻再做設定。

## 不做（先看紅框夠不夠用）
- 推播／聲音提醒、可自訂門檻。
