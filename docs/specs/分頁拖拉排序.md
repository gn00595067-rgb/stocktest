# 分頁拖拉排序（股票輸入（仿Yahoo））

## 為什麼
2026-11-17 回饋：分頁要重新排序時，原本是選一個分頁再按 ◀ ▶ 一格一格移，分頁一多就要點很多次。希望能用拖的。

## 做法（MVP）
- 收合區「⚙️ 新增股票・搜尋・編輯分頁・輸入日期」裡的 ◀ ▶ 換成一顆「⇅ 排序分頁」。
- 按下去跳出視窗，裡面列出所有分頁（直排）；用滑鼠或手指按住拖到想要的位置，可連續拖好幾個。
- 按「儲存順序」才寫入；按「取消」或關掉視窗＝不改。
- 只排這個登入帳號看得到的分頁；看不到的分頁（沒權限的買賣人）位置不動。

## 範圍外
- 直接在分頁列上拖（Streamlit 的分頁列是 radio，做不到直接拖；之後真的需要再評估）。

## 技術
- 不加第三方套件：自寫一個本機 Streamlit 元件 `services/tab_sorter/`（純 HTML＋JS，pointer 事件，滑鼠／觸控都可）。
- 寫入：`services/group_portfolio.py::reorder_groups(sess, owner, ordered_ids)`。
