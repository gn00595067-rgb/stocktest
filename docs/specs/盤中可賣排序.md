# 盤中可賣排序（股票輸入（仿Yahoo）持股表）

## 需求（2026-11-13 老闆錄音）
> 我在盤中的時候，希望系統能夠幫我判斷一件事……今天可以買賣的，就是在 10% 以內的。系統應該要提醒我，
> 有獲利的它提醒我，不用我看這麼多的股票……把今天已經有獲利的股票先展示出來在上面。
> 現在只是按照我投資的金額大小。盤中的時候，我會希望有獲利我就可以今天賣了，它放在上面。

老闆在截圖勾的欄位：股名、股價、底價、市值、未實現損益——判斷的依據就是「現價 vs 底價」。

## 規則
每檔有持股、有今天報價的股票分三區：
1. **💰 已過底價**：現價 ≥ 底價（今天賣出扣手續費、證交稅一定不虧）。區內依「現價高出底價 %」大到小。
2. **📈 今天有機會**：現價 < 底價 ≤ 今天漲停價。漲停價＝昨收 ×1.1，依升降單位無條件捨去（「10% 以內」）。
   區內依「還差幾 %」小到大（最接近的在上）。
3. **其他**：漲停也到不了底價、沒報價、沒持股（自選股）。照原本順序（市值大到小）。

- 每區上面一行小標題（含檔數）；股名下面加一行標示「💰 已過底價 +x.x%」／「📈 差 x.x%」。
- 表格上方開關「💰 可賣的排上面」：**盤中預設開、收盤後預設關**（收盤後照原本市值排序看總覽）；手動切換後這次登入期間記住。
- 只改排序與標示，不改任何計算、不拿掉欄位（其他同事也用這頁）。

## 不做（先問老闆）
- 只顯示打勾的欄位／把「其他」收起來：先看排序是否就夠用。
- 推播／聲音提醒。

## 程式
- `services/group_portfolio.py`：`limit_up_price(prev_close, is_etf)`、`sell_status(row)`、`sellable_first(rows)`（純函式、有測試）；`summarize_group` 的列多帶 `is_etf`。
- 頁面 `_holdings_table` 只負責開關、分區標題、標示。
