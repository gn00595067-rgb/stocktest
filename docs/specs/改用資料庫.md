# 改用資料庫（Neon Postgres）— 完整轉移說明

> 狀態：**2026-10-02 已切換**（正式資料在 Neon）；GitHub Actions 每日備份已啟用並手動驗證成功。
> 最後更新：2026-10-02

## 1. 為什麼要換

- **慢**：目前把 Google 試算表當資料庫，每次存檔都要整份寫回試算表、再讀回來核對（優化後仍約 2～5 秒）。
- **怕出錯**：app 記憶體一份、試算表一份，兩邊不一致時寫回就可能蓋掉資料，過去的掉單都出在這裡。
- 換成真正的資料庫後，存檔只寫入有變動的那幾筆（預估 1 秒內），也不再有「兩份資料要同步」的問題。

## 2. 換完之後的樣子

| | 現在（試算表模式） | 換完（資料庫模式） |
|---|---|---|
| 正式資料存在哪 | Google 試算表 | Neon Postgres |
| 存檔 | 整份寫回試算表 | 只寫入變動的筆數 |
| Google 試算表 | 正式資料 | **唯讀備份**：每天自動匯出一份，另有滾動備份分頁 |
| 同事操作 | — | **完全一樣**，頁面不變 |

切換開關只有一個：Streamlit Secrets 有沒有設定 `DATABASE_URL`。
- 有 → 資料庫模式（就算 `USE_GOOGLE_SHEET=true` 也不會再從試算表載入或寫回）。
- 沒有 → 維持原本的試算表模式。

## 3. 資料現況（2026-10-02 唯讀讀取試算表）

| 表 | 筆數 |
|---|---|
| trades 交易 | 544（最大 id 662；當天同事仍在記帳，數字會變） |
| custom_match_rules 自定沖銷 | 286（其中 26 條指向已刪除的交易＝「失效規則」；5 個買進批被超額配對） |
| user_accounts 帳號 | 1 |
| user_trader_bindings 權限綁定 | 0 |
| traders 買賣人 | 3 |

失效規則照原樣搬過去（見 DECISIONS：只警示、不自動刪），所以資料庫**不加外鍵限制**，行為與現在的 SQLite 完全相同。
同理，Postgres 的文字欄位**不限長度**（SQLite 從不檢查；主檔已有 24 字的類股指數代號）。

## 4. 程式改動（Claude 負責，已完成）

1. `requirements.txt`：加 `psycopg2-binary`（Postgres 連線套件）。
2. `db/database.py`：
   - 設了 `DATABASE_URL` → 連 Postgres，`pool_pre_ping`（Neon 休眠醒來第一次連線不報錯）。
   - 資料庫模式下停用「從試算表載入」與「commit 後寫回試算表」。
   - Postgres 建表不帶外鍵（理由見第 3 節）。
3. 讀取交易／沖銷規則一律固定順序（交易依 id、規則依賣出 id＋買進 id）：Postgres 不保證回傳順序，
   而超額配對時規則套用順序會影響結果；固定後兩種資料庫算出的損益逐位元一致（已用正式資料驗證）。
4. `services/sheet_sync.py`：SQL 裡的 `user` 欄位加引號（`user` 在 Postgres 是保留字，不加會讀到「目前登入的資料庫帳號」而不是交易人，**資料會默默錯掉**）。
5. `scripts/migrate_sheet_to_db.py`：搬家工具。
   - 只讀試算表，絕不寫回。
   - 目標資料庫有資料時預設拒絕（要加 `--replace` 才會清空重灌）。
   - 搬完逐表、逐筆比對內容，完全一致才算成功；並把自動編號調到最大 id 之後。
   - `--verify-only`：只比對試算表與資料庫是否一致，不寫入。
6. `scripts/export_db_to_sheet.py`：把資料庫匯出到試算表當備份（沿用寫回試算表的防呆：資料庫筆數異常變少就中止，不會用殘缺資料蓋掉備份）。
7. `.github/workflows/backup-db-to-sheet.yml`：每天台灣時間 22:00 自動執行匯出備份；也可在 GitHub 手動觸發。
8. app 側欄：資料庫模式顯示「📦 資料庫模式」，管理者可按「匯出備份到 Google 試算表」。

   ```
   NEON_DATABASE_URL=postgresql://...
   ```

## 6. 出問題怎麼退回（回到試算表模式）
1. 先把資料庫最新資料匯出到試算表：`python scripts/export_db_to_sheet.py --force`（或側欄按鈕）。
2. Streamlit Secrets 刪掉 `DATABASE_URL` 那一行 → app 重啟後回到試算表模式。
3. 不要跳過第 1 步：切換後在資料庫模式記的交易，只存在資料庫裡。
