# 仿Yahoo 展開區：每筆買進的未實現、今天買進若當沖的損益（新舊版一起做）

## 需求（2026-11-23 Peggy，截圖標註）
1. 「明細裡的市值右邊可以加一個未實現損益嗎？更直覺判斷今天適不適合做當沖（也是要算扣完稅費的）」
2. 「最上面做一個當日買入的，若做當沖的損益明細，並做在這一頁就要能收起來或展開，不然又會佔太大版面」

## 規則
### 1. 交易明細多一欄「未實現(扣費稅)」（放在市值右邊）
- **買進**：這筆買進**還沒被沖掉的股數**（照目前的沖銷：自定規則＋其餘先進先出，同仿Yahoo 持股）
  若現在全部用現價賣掉，扣賣出手續費、證交稅後，減掉這部分的成本（買價×股數＋買進手續費照股數比例）。
  - 手續費率用這個買賣人的折數；證交稅一般 0.3%、ETF 0.1%（這欄一律用一般稅率，當沖試算看第 2 點）。
  - 已經全部沖掉的買進顯示「已沖完」；只沖掉一部分的，下面小字標「剩 N 股」。
- **賣出**、新增中的列：顯示「—」（賣出的損益看下面的沖銷明細）。

### 2. 「今天買進若現在當沖賣出」試算（展開區最上面，預設收起來）
- 只看**今天**買進、還沒被沖掉的股數（這個買賣人、這檔）。沒有就不顯示。
- 收起來時一行：「⚡ 今天買進若現在當沖賣出：預估 ±X（N 筆，共 Q 股）」；點開看每筆：
  買進價、剩餘股數、若現價當沖賣出的損益（扣手續費＋**當沖證交稅 0.15%**，ETF 0.1% 不減半）、報酬率，最後一列合計。
- 只是試算，不寫任何資料。
