# 操作紀錄（誰在什麼時候新增／修改／刪除了哪筆交易，可還原）

## 需求（2026-11-25）
11/23 聯電一筆賣出在新系統被刪，查不出是誰、什麼時候刪的。Elsa：「那未來我要怎麼確認這個狀況？」
Jonathan：加「操作紀錄」，以後每次刪除或修改交易都記下時間、帳號、改了什麼，數字不對時打開就能查到，也能直接還原。

## 記什麼（資料表 `trade_audit`，只新增，不動既有表）
| 欄 | 說明 |
|---|---|
| at | 時間（UTC，畫面顯示台灣時間） |
| actor | 登入帳號 |
| source | 哪個系統／頁面（例：新系統・仿Yahoo、新系統・對帳單匯入、舊系統・仿Yahoo） |
| action | add 新增／edit 修改／delete 刪除／match 改沖銷配對／import_fix 照對帳單修正／import_delete 匯入時刪除（合成一筆、對帳單沒有的手 key）／undo_import 復原匯入／restore 從紀錄或「復原」還原 |
| trade_id、trader、stock_id、trade_date | 哪一筆（方便篩選） |
| before | 改／刪之前的完整快照（交易＋沖銷規則＋委託書號，格式同新系統「復原」用的快照） |
| after | 改之後的值（新增、修改、還原才有） |
| note | 補充（例：一次刪多筆共 N 筆、匯入批次） |
| restored_at、restored_by | 從紀錄還原過的時間與帳號（避免重複還原） |

## 記哪些操作
- 新系統：仿Yahoo 新增、修改、刪除（單筆、一次刪多筆、刪除此股全部）、改沖銷配對、「復原」；
  對帳單匯入的照對帳單修正、合成一筆刪掉的、對帳單沒有而勾選刪除的手 key、復原匯入。
- 舊系統（只剩備用，但同一份資料）：仿Yahoo 修改、刪除（單筆、一次刪多筆）；對帳單匯入的修正／刪除、復原匯入。
- 第一版不記：主檔設定的批次重算（手續費、證交稅）、股號更名搬資料、自定沖銷設定頁（之後要再加）。

## 畫面（新系統「操作紀錄」頁，管理者）
- 篩選：日期區間（預設最近 7 天）、買賣人、股票、動作。新到舊。
- 每列：時間、帳號、來源、動作、買賣人、股票、內容（例：「刪除 11/23 賣出 2,000 股 @88.30」「修改 股數 1,000→2,000」）。
- **還原**：刪除／修改／改配對／匯入修正與刪除的紀錄有「還原」鈕 → 照 before 快照寫回（刪除＝插回原 id、修改＝改回原值，沖銷規則與書號一起），
  檢查規則同「復原」（例：還原賣出時持股要夠）。還原後標「已還原（時間、帳號）」，同時新增一筆 restore 紀錄。
- 紀錄寫在同一個資料庫交易裡：操作失敗紀錄也不會留下；紀錄寫不進去，操作也不成功。

## 程式
- 新版：`src/lib/data/audit.ts`（表、寫入、查詢、快照）、各 action 呼叫；頁面 `/audit`；還原 `restoreFromAuditAction`（yahoo/actions.ts）。
- 舊版：`services/audit_service.py`（同一張表、同快照格式），仿Yahoo 與對帳單匯入呼叫。
