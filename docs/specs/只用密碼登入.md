# 只輸入密碼登入（老闆＋開發者）

## 需求（2026-10-19）
- 老闆在 iPad 上不想每次打帳號；未來只有老闆一人使用 → 只要密碼。
- 開發期間保留一組開發者密碼，之後停用。
- 同一台裝置要記住登入，不用每次重登。

## 設計
- 登入頁只剩「密碼」＋「記住我（這台裝置 90 天內免登入）」。
- 系統比對所有**啟用**帳號的密碼，對上哪一組就以那個帳號登入；所以各帳號密碼不能重複（新增帳號、重設密碼時擋），至少 8 碼。
- 輸錯鎖定：全站 1 分鐘內輸錯 5 次，暫停 1 分鐘（沒有帳號這道關的補強）。
- 帳號整理（Jonathan 選）：新建「老闆」（12345678）、「開發者」（dev12345678，兩組不能一樣），都是管理者；admin、money、peggy、tester 停用（不刪）。admin 的仿Yahoo 分頁搬給「老闆」、tester 的給「開發者」。交易掛在買賣人底下，不受帳號影響。
- 記住登入沿用原機制：cookie＋網址 token（iPad Safari 擋 cookie 時靠網址 `?rt=`）。iPad 建議在仿Yahoo 頁「分享 → 加入主畫面」，從圖示打開就帶著 token。改密碼／停用帳號後舊 token 失效，要重新登入並重新加入主畫面。

## 不做
- 不刪舊帳號（停用即可，需要可再啟用）。
