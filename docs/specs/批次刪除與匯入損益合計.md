# 仿Yahoo 一次刪多筆、對帳單匯入預估損益合計（11/19 Elsa）— 新舊版一起做

## 需求
1. Elsa 錄影：聯電 11/19 要整批重來，只能在仿Yahoo 展開區一筆一筆按 🗑 →「確定刪除」，每刪一筆整頁重跑，很慢，「今天一直卡在這裡」。
2. 對帳單匯入預覽：「切換不同的沖銷方式，但損益不會加總」——總數在最上面那行、或收起來的「預估損益分股看」，切換時看不到。

## 規則
### 一次刪多筆（仿Yahoo 展開區，交易明細下方）
- 收合區「🗑 一次刪多筆」：這檔（分頁內）的全部交易列成表，第一欄勾選。
- 「快速勾選」下拉：不預先勾／某一天的全部（有交易的日期，新到舊）。選了就把那天全部先勾好，還可以再手動增減。
- 勾了幾筆就顯示「刪除勾選的 N 筆」，要再勾「確定刪除（連同沖銷配對）」才按得下去；一次存檔、整頁只重跑一次。
- 每筆都檢查買賣人權限；沒權限的整批不刪。
- 跟單筆刪除一樣：沖銷規則一起刪。（舊版單筆刪除也沒有復原；新版單筆有「復原」，批次刪除也要能復原整批。）

### 匯入預估損益合計
- 沖銷方式（與當沖範圍）選項正下方直接顯示「👉 照目前選的方式：預估這次多出已實現損益 ±N（M 筆賣出）」，切換馬上看到。
- 預覽表（新增／要確認那張）有「預估損益」欄時，最後加一列「合計」。
