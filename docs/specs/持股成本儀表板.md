# 持股成本儀表板（新舊版一起做）

## 需求（2026-11-23 Elsa）
Peggy姐 上週請 Elsa 用 Claude 做了一個「持股成本儀表板」（claude.ai Dashboard），每天要叫 AI 進去更新。
Elsa：「雖然也可以叫 AI 每天進去更新，但想看是否其實可以內建在系統裡。」Jonathan：新舊版都做。

原版資料是從新版仿Yahoo 各分頁抄的（「新股票系統收盤 2026/11/20」）。內建後直接用系統的交易＋即時報價，不用每天更新。

## 口徑（照原版）
- 每個分頁算一份：**市值**＝分頁「持有股票市值」；**未實現**＝分頁「未實現損益（扣賣出費稅）」；
  **成本＝市值－未實現**（含買進手續費，也含預估賣出手續費、證交稅）。**報酬率＝未實現÷成本**。
  計算一律用仿Yahoo 的 `summarize_group`（同一個函式），所以跟仿Yahoo 畫面上的數字一致。
- **三個帳戶**（分頁名稱 → 顯示名稱）：
  - Peggy姐：「P11/3 短線」→ 11/3短、「11/17」→ 11/17、「Peggy姐」→ P姐
  - 豪哥：「豪哥」
  - 雅雲：「雅雲」
- **三帳戶合計**＝上面五個分頁相加。
- **扣除美美**：「美美」分頁的持股裡，**也在「全部」分頁有持股的股票**才扣；
  不在的列出來但不扣。
- **淨投入成本（大數字）**＝三帳戶合計成本－美美扣除成本；市值、未實現同樣相減。
- **圓環**＝淨市值÷淨成本，下面小字＝淨未實現÷淨成本。
- 分頁一律取「老闆」帳號的分頁設定（Peggy姐 用的那組）。找不到某個分頁就在畫面上提醒、當 0 算。

## 版面（照原版）
1. 深色總覽卡：標題、資料時間（報價時間；收盤後＝收盤價）、大數字「扣除美美後・原始投入成本」、
   四張小卡（目前市值、未實現損益、三帳戶合計成本、已扣除的美美成本）、右邊圓環；下方三個帳戶各一條
   （成本、市值、報酬率，進度條＝市值÷成本，小字列出含哪些分頁）。
2. 「成本從哪裡來」瀑布圖：五個分頁的成本一段段疊成合計，再扣美美，就是淨投入；實心＝目前市值、淡色＝帳面虧損。
3. 統計表：帳戶｜分頁／股票｜市值｜未實現損益｜成本｜報酬率；Peggy姐 小計、三帳戶合計、減：美美（逐檔）、
   美美小計、扣除美美後總計。
4. 收合區「美美的持股與計算方式」：美美每檔股數、市值、未實現、是否扣除；加上口徑說明。
