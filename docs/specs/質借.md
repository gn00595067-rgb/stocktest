# 股票質借 — 規格

> 狀態：MVP（2026-10-29）
> 需求來源：Peggy 2026-10-29：「我有把股票去質借，借出錢來……我原本有股票 20 張，可是我拿了 16 張去跟銀行借款，
> 所以我現在在帳上雖然有 20 張，但是能夠動用的是 4 張。」
> Jonathan 2026-10-29：她說的「儀表板上面」不是指最上面，**只要畫面能分出可動用／不可動用就好**。

## 1. 要解決什麼
- 質借後股票仍是她的，但押在銀行的部分**不能賣**。系統只看到 20 張，哪些不能動要自己記。

## 2. 核心判斷：質借**不是交易**
- 不新增買賣、不動沖銷、不影響均價／市值／已實現／未實現／報酬率（`pnl_engine` 完全不碰）。
- 只是一個標記：「某人某檔目前有 N 股質押中」。帳上持股照舊，另外顯示可動用多少。

## 3. MVP 範圍
### 3.1 資料
- 新表 `pledges`（trader, stock_id 為主鍵；shares 質押股數；updated_at）。
- 只記「**目前**質押幾股」，不記歷史、借款金額、銀行。還款解除＝改成 0（刪掉該列）。
- 比照 `sim_states`：`services/pledge_service.py` 第一次用到才建表、用 engine 直接寫，部署免 Reboot、不讓交易快取失效。
  試算表備份不含此表。

### 3.2 畫面（股票輸入（仿Yahoo））
1. 持股表「持有股數」欄：有質押的股票在股數下加兩行橘色小字「質押 16,000」「可動用 4,000」（欄位窄，一行放不下）。
2. 展開某檔 → 最上面一行「🏦 質押中股數」輸入框＋「儲存」：填股數（step 1000），0＝沒有質押。
3. 賣出：賣出股數超過可動用股數時，加一條提醒「有 X 股質押中，可動用只有 Y 股」，
   跟其他提醒一樣要勾「我確認以上沒問題」才能送出——**只提醒、不擋**（可能已還款、或忘了改質押數）。
4. 質押股數 > 目前持股：小字第二行改成「超過持股，請確認」。

### 3.3 不做（MVP）
- 借款金額、銀行、維持率、利息、到期提醒。
- 總覽卡、庫存損益頁、庫存模擬頁的質押顯示（等 Peggy 用過再說）。

## 4. 驗收（以 Peggy 例子）
- 某檔持有 20,000 股，存質押 16,000 → 持有股數下出現「質押 16,000」「可動用 4,000」；均價、市值、損益與質押前完全相同。
- 賣出 5,000 股 → 出現質押提醒要勾確認；賣 4,000 股 → 不提醒。
- 質押改 0 → 小字消失。
